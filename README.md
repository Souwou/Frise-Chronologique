# La Grande Frise

L'histoire du monde, des premiers dinosaures jusqu'à aujourd'hui, une leçon par jour.

**Appli :** https://souwou.github.io/Frise-Chronologique/

- **Aujourd'hui** : la leçon du jour, placée sur la frise, avec « à retenir », une anecdote et une question.
- **Frise** : les 11 périodes, de la Pangée à nos jours, et toutes les leçons de chaque période.
- **Réviser** : chaque leçon lue devient une carte de révision (5 boîtes, rappels espacés).
- **Journal** : toutes les leçons, avec recherche.

L'appli s'installe sur l'écran d'accueil du téléphone et fonctionne hors connexion.
Les couleurs des périodes géologiques sont celles de l'échelle internationale des temps géologiques.

## Mise en ligne
Settings → Pages → Source : *Deploy from a branch*, branche `main`, dossier `/ (root)`.

## Contenu
Les leçons sont dans `data/lessons.json`. Voir `CLAUDE.md` pour le format et la façon d'en ajouter.
